# ProcureFlow

ProcureFlow is a local-only React application. It runs entirely in the browser and stores demo data, accounts, and edits in `localStorage`.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite, usually `http://localhost:5173`.

Create an account from the registration page to access the application. No external services, hosted backend, or environment variables are required.

## Other commands

```bash
npm run build
npm run lint
npm run typecheck
```

To reset all local demo data, clear the site data for the local Vite URL in your browser.
